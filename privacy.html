Privacy & data handling

LinkOps is a Forge application for Confluence Cloud. The current implementation does not depend on an ASHBIZCON-operated external SaaS backend, advertising system, analytics service, or AI provider.

Confluence data read

To scan and repair links, LinkOps reads page metadata and page storage-format content available to the app/user context. It derives operational evidence such as source page identifiers/titles, space identifiers, destination URLs, link type, validation status, status code, timestamps, and related audit evidence.

Data stored in Forge

  • LinkOps settings and onboarding state.
  • Saved migration and exclusion rules.
  • Scan-history snapshot metadata and link evidence.
  • Safe Repair audit evidence, including page ids/titles, versions, hashes, expected changes, outcomes and verification results.
  • Scheduled-scan run state and bounded error summaries.

Complete page bodies are not intentionally persisted merely for scan history.

Browser-local recent scan cache

The Custom UI can keep the most recent completed scan in browser IndexedDB for up to 24 hours so a normal refresh does not immediately show an empty dashboard. This cache is local to the browser profile, site/account scoped, versioned, age-limited, best-effort only, and is not a substitute for authoritative Forge history snapshots.

External URL validation

When enabled, LinkOps makes outbound HTTP(S) requests to public destinations referenced by Confluence pages. The destination server can observe ordinary request metadata. LinkOps restricts protocols, rejects credential-bearing URLs, blocks local/private/metadata-style targets and non-standard ports, re-checks redirects, and uses bounded redirects, timeouts, retries, deduplication and concurrency.

Repair behavior

Page writes occur only through the reviewed Safe Repair workflow. LinkOps uses server preflight, explicit confirmation, version/hash checks, a fresh page read before mutation, conflict skipping, audit evidence, and post-repair verification. Scheduled content repair is not performed.

Customer controls

Administrators can disable external validation, disable scheduled evidence collection, archive saved migration/exclusion rules, and choose when to save historical evidence.
